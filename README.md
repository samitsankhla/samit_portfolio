# Samit Sankhla — Portfolio Website

This is a personal portfolio website built with **React.js** and **Tailwind CSS** to showcase my skills, projects, and internship experience as a web developer.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [https://samit-portfolio-self.vercel.app/] with your browser to see the result.

You can start editing the source files in the `src` folder. The page updates automatically as you make changes.

## Features

- Responsive design
- About Me and Skills sections
- Projects showcase
- Internship experience
- Resume download
- Contact and social media links
- Modern dark-themed UI

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- HTML5 and CSS3

## Projects

- **Real Estate Marketplace** — A platform connecting property buyers and sellers.
- **Training and Placement Cell Web App** — A web application for managing student placement activities.
- **Excel Analytics Platform** — A platform for spreadsheet data analysis and visualization.

## Deployment

You can deploy this portfolio using platforms like [Vercel](https://vercel.com/) or [Netlify](https://www.netlify.com/).
